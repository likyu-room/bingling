# 빙글링 1.3 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 자체 캡처·바로 스포이트(A), 편집 창 흐림·스포트라이트·스포이트(B), 창 없이 바로 꾸미기(C), 가릴 곳 자동 찾기(D)를 빙글링에 넣는다.

**Architecture:** 단축키는 `TriggerGesture.Action`이라는 새 속성으로 나눠 `TriggerService`가 동작별 이벤트를 낸다. 캡처와 스포이트는 기존 `IPlatformServices.CaptureScreen`(GDI)으로 커서가 있는 모니터를 찍어 Avalonia 최상위 창에 보여 준다. 편집 창 기능은 기존 `ImageEditRenderer`(미리보기 = 결과)와 도구 뷰모델에 더한다. OCR·얼굴 인식은 Windows PowerShell 5.1로 WinRT를 불러 JSON으로 받는다(빌드 구조는 그대로 net10.0).

**Tech Stack:** C#/.NET 10, Avalonia 12, SkiaSharp, Magick.NET, SharpHook, xUnit(+Avalonia.Headless), Windows PowerShell 5.1(WinRT `Windows.Media.Ocr`, `Windows.Media.FaceAnalysis`).

**Spec:** `docs/superpowers/specs/2026-10-22-bingling-1.3-design.md` (반드시 읽기)
